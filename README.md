<h2>About the project</h2>
<p>
  This is a multi-page application that allows users to create, edit, and organize personal notes, designed for mobile, tablet, and desktop.
</p>

<h2>Implemented features</h2>
<ul>
  <li>User registration</li>
  <li>User authentication</li>
  <li>Personal profile with basic user information</li>
  <li>Notes section with the ability to filter notes by categories</li>
</ul>
